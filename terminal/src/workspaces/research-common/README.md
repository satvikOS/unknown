# research-common

This folder is not a workspace. It holds code shared by the Company, Markets & macro and Research workspaces:

- `api.ts`: `useApi<T>(path, params, options)`. It is a typed read of the plugin routes (`/api/company`, `/api/macro`, `/api/research`) through the shared query cache (`useQuery`), so caching and header provenance stay the same. These routes read the research store and registry, not the core's event log, so `useApi` is `seqDriven: false` by default: a new core seq does not refetch them (the Company tearsheet is about 640 kB). They are fetched when a view opens, on Refresh, and on a stream reconnect or reset, and the header shows no seq for them. The issuer search also matches the core's instrument master and passes `{ seqDriven: true }`. Empty parameters are dropped. `apiPath(...)` encodes segments like the core client does.
- `format.ts`: exact decimal-point shifting (a ratio shown as a percentage with nothing rounded), API instant parsing, the API's as-of rule (`checkInstant`), and extraction of the populate command named in an unavailable reason. `POPULATE` lists the documented command for each source (SEC, Treasury, ECB, the fixture study) with the arguments its command line requires; the SEC, Treasury and ECB ones are exactly what the backend's reasons write, and the study one adds the `--out <DIR>` that the research API's reason leaves out. `populateCommands` shows the reason's commands first, then the documented ones, and replaces a partial command with the complete one. `checkInstant` refuses an impossible calendar date in an instant (2026-02-30T10:00Z), which `Date.parse` would roll over; `shownOf` writes "50 of 73" for a list the API cut short. It also formats float statistics, labelled as such.
- `chartMath.ts` and `charts.tsx`: inline SVG line and range charts with no dependency. A chart is an `<svg role="img">` with a title and a text summary. Gaps stay gaps, and markers carry the exact value text. The range chart can draw one reference marker (the owner's price input on the DCF football field).
- `parts.tsx`: panels, the `Unavailable` notice (reason verbatim plus command; `commands` adds the documented ones), status tags, unit-aware values, rates as decimal plus exact percentage (`RateValue`), external links (a null link shows the text alone), instants and a JSON tree for nested records. The JSON tree shows a `*_ns` value exactly from the API's `*_ns_str` sibling (and leaves the sibling's own row out); any other integer beyond 2^53 is marked with "≈", because JSON.parse has already rounded it.
- `research.css`: local layout only. Colours come from the shared theme tokens.
